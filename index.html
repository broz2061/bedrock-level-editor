O que este site faz

O level.dat guarda as configurações do mundo, mas é um arquivo binário que editor de texto nenhum consegue abrir. Este site resolve isso:

🔓

Decodifica

Lê o formato NBT do Bedrock (com o cabeçalho de 8 bytes) e mostra tudo como um JSON legível.

🎛️

Edita do jeito fácil

Um painel guiado com interruptores e opções clicáveis para as configurações mais usadas, sem decorar números.

💾

Gera o arquivo de volta

Converte o JSON editado para um level.dat válido, preservando cada tipo de dado (byte, int, long, float…).

Como funciona

Quatro passos, menos de um minuto.

1

Escolha o arquivo

Selecione ou arraste o level.dat do seu mundo.

2

Decodifique

O conteúdo aparece em JSON, pronto para editar.

3

Edite

Use o painel guiado ou altere o JSON diretamente. Os dois ficam sincronizados.

4

Salve e baixe

Baixe o novo level.dat (e, se quiser, o level.dat_old) e coloque na pasta do mundo.

O que você pode editar

Tudo que estiver no arquivo pode ser alterado no JSON. O painel guiado cobre os campos mais populares:

🎮

Modo de jogo e dificuldade

Sobrevivência, Criativo, Aventura; Pacífico até Difícil.

📜

Gamerules

keepinventory, mobgriefing, pvp, ciclo de dia/noite, randomtickspeed e dezenas de outras.

🌍

Mundo

Nome, seed, ponto de spawn, clima, trapaças ativadas e outras opções.

⚠️ Faça backup antes! Copie o level.dat original para outro lugar antes de substituir. Se algo der errado, basta restaurar a cópia. Alterar certos campos pode impedir o mundo de abrir.

Perguntas rápidas

Meu arquivo é enviado para algum servidor?

Não. Toda a leitura e a geração do arquivo acontecem no seu navegador, com JavaScript. Nada é enviado para a internet.

Onde fica o level.dat?

Dentro da pasta do mundo, em minecraftWorlds. No Windows (Bedrock/UWP): %LocalAppData%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\minecraftWorlds\. No Android: Android/data/com.mojang.minecraftpe/files/games/com.mojang/minecraftWorlds/ (versões novas do Android podem exigir um gerenciador de arquivos).

E o level.dat_old?

É uma cópia do arquivo anterior que o jogo mantém ao lado do level.dat. Ele tem o mesmo formato, então o editor também abre esse arquivo. Na hora de salvar você pode baixar um level.dat_old junto.

Funciona com Minecraft Java?

Não. O Java usa outro formato (NBT compactado e em outra ordem de bytes). Este editor é só para o Bedrock.

Editor de level.dat

Tudo roda no seu navegador. Nenhum arquivo é enviado para a internet.

1 Escolha o seu level.dat

Selecione o arquivo do mundo (também funciona com o level.dat_old).

Onde encontro o level.dat?

Windows: %LocalAppData%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\minecraftWorlds\ e abra a pasta do seu mundo.
Android: Android/data/com.mojang.minecraftpe/files/games/com.mojang/minecraftWorlds/

2 Código JSON (edição completa)

Cada campo é {"type": "...", "value": ...}. Edite só o value e mantenha o type. Flags verdadeiro/falso são byte: 1 = ligado, 0 = desligado.

Tipos: byte -128..127 · short · int · long (64 bits) · float/double (decimais) · string (texto)

3 Editor guiado

A mesma edição, sem precisar mexer no código. Qualquer mudança aqui atualiza o JSON acima, e vice-versa.

O JSON acima tem um erro. Corrija-o para voltar a usar o editor guiado.

4 Salvar e baixar

Gera um level.dat válido a partir do que está no editor.

Ao baixar dois arquivos, o navegador pode pedir permissão para “baixar vários arquivos”. Aceite.
